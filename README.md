# physicslab

Personal notes, derivations and simulations I write to understand physics better.

Nothing here is meant to be authoritative or polished — it is a working notebook. Expect rough edges and mistakes.

## Layout

- `notes/` — dated notes and derivations (`YYYY-MM-DD-topic.md`, `.html`, or a folder)
- `experiments/` — self-contained simulations and programs, one folder each

Each experiment folder has its own `README.md` saying what it is and how to run it.
